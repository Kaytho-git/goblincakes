# Listor och tabeller

```html
<ul>                <!-- punktlista; <ol> = numrerad -->
  <li>Pilbåge</li>
  <li>Pilar</li>
</ul>

<table>
  <thead><tr><th>Namn</th><th>Poäng</th></tr></thead>
  <tbody>
    <tr><td>Bo</td><td>655</td></tr>
  </tbody>
</table>
```

Tabeller är till för **data** (resultatlistor!), inte för att placera ut saker på sidan – det gör
man med CSS.
